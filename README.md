* **Rapid-Fire Minigames:** Includes 2 fully playable, chaotic minigames with more variations in active development.

## 💡 About this Project
This is my very first time diving into game development! I decided to replicate a WarioWare-style game to challenge myself with micro-mechanics and fast-paced logic. I am consistently learning the Godot engine and plan to expand this with a massive library of weird, frantic minigames over time.
